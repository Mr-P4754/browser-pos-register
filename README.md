# イベント・店舗用 簡易POSレジシステム (Simple POS System)

ブラウザ単体・オフラインで完結して動作する、イベント出店・小規模店舗・同人即売会向けの高性能・軽量Web POSレジシステムです。PWA（Progressive Web Apps）に対応しており、PC、タブレット、スマートフォンへインストールしてネイティブアプリのように利用可能です。

🌐 **[今すぐWebアプリを開く（GitHub Pages）](https://mr-p4754.github.io/browser-pos-register/)**

---

## 🌟 主な機能と特徴

### 1. レジ会計・スマート販売
- **バーコードスキャン対応**: Webカメラを利用した高速バーコード・QRコード読み取り（ZXing / Quagga2による高感度リアルタイム検知）。
- **商品ダイレクト選択 & 自由入力販売**: 事前登録された商品ボタンからのワンタップカート追加に加え、その場での自由な商品名・金額入力による販売に対応。
- **柔軟な割引機能**: カート全体へのパーセント割引（%OFF）および固定値値引き（円引）。
- **金種ステッパー預かり金照合**: 1円・5円・10円・50円・100円・500円・1,000円・5,000円・10,000円の各硬貨・紙幣の枚数ステッパーを備え、受取金額の照合やお釣りの計算ミスを防止。
- **ワンタップお釣り消滅 & 音声案内**: 会計完了時のお釣り表示はお客様確認後に画面タップで即時リセット。

### 2. 在庫管理
- **リアルタイム在庫追跡**: 会計完了時に自動で在庫数を減算。
- **ステッパー & 直接入力調整**: 商品ごとの在庫数を「+ / -」ボタンおよび数値の直接編集で瞬時に更新可能。
- **レスポンシブ最適化**: PC・iPad・タブレット画面でも押しやすく見やすいカードUI設計。

### 3. バーコードラベル・商品タグ印刷
- **マルチフォーマット印刷**:
  - **商品貼付ラベルシート（24面 / 44面）**: A4サイズのラベルシール用紙に対応。商品名・税込価格・バーコードのみを整然とレイアウト。
  - **単品印刷・単票カード**: POP用や個別の商品タグ向け印刷。
- **自動バーコード採番**: JANコード互換の独自コード自動発行に対応。

### 4. 売上管理・QRコード集計
- **日別売上ダッシュボード**: 売上総額・客数・平均客単価・時間帯別グラフ・商品別ランキングを可視化。
- **複数レジ合算（オフライン連携）**:
  - **QRコード売上共有**: 売上データを高密度QRコード（Version 1〜40自動最適化）に出力し、親機カメラで読み取るだけでネットワーク不要のデータ統合が可能。
  - **JSONエクスポート / インポート**: ファイル送受信によるバックアップ・合算に対応。
- **取消（Void）処理**: 誤会計時のレシート単位での取消・在庫戻し処理。

### 5. PWA（Progressive Web App）対応
- **完全オフライン動作**: Service Worker による全アセットキャッシュにより、通信環境のない野外イベントや地下催事場でも安定稼働。
- **ホーム画面追加**: スマートフォンやタブレットのホーム画面に追加してフルスクリーン起動可能。

## 🚀 利用方法

### そのまま起動する場合
ローカルサーバー（PythonやVSCode Live Serverなど）を起動し、ブラウザでアクセスします。

```bash
# Pythonの場合
python -m http.server 8080

# または Node.js http-server
npx http-server -p 8080
```

ブラウザで `http://localhost:8080` を開きます。

## 🛠️ 技術スタック
- **フロントエンド**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **バーコード/QRエンジン**: Quagga2, ZXing-js, JsBarcode, qrcode-generator
- **オフライン対応**: Service Worker (Cache Storage API), Web App Manifest
- **データ永続化**: ブラウザ LocalStorage API
